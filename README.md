# WeScribe Release Notes POC

A static proof of concept for visually rich product release notes, built from markdown with layout directives and hosted on GitHub Pages.

The design is in [docs/superpowers/specs/2026-10-17-release-notes-poc-design.md](docs/superpowers/specs/2026-10-17-release-notes-poc-design.md). Loose ideas are collected in [IDEAS.md](IDEAS.md).

This README will grow to cover the content model, the stored format, the export rules and the format options considered, once the build starts.
