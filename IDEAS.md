# Ideas

A running list of ideas for WeScribe release notes and the editor behind them. Nothing here is committed work. Add freely, prune later.

## Editor

- **Split section slash command.** A `/split section` command that splits the current section into two sections at the cursor. Blocks before the cursor stay in the original section, blocks after it move into a new section directly below. The new section starts as a single column so the author can then pick a different layout for either half.

## Blocks

- Planned block types are listed in the README under "Planned block types": carousel, feature card, image with caption, and modal behavior on any block.
